# Feather Client

**Feather Client** is the Minecraft Java launcher: 40 built-in mods, voice chat, Fabric / Forge import, HUD, FPS boost.


## What's new in v0.2.0.338 (August 1, 2026)
- Current official launcher version is `0.2.0.338` (dawn.gg)
- Java + Bedrock; profiles, mods, and voice still carry over
- Login, pick 1.8.9 / 1.20.1 / 1.21, launch
- Old Feather `2.7.1` is no longer the current public line


## How to use
1. Download v0.2.0.338.
2. Extract `Feather-Client.zip`.
3. Login a Microsoft account.
4. Pick 1.8.9 / 1.20.1 / 1.21. Launch.


## Key Features
- 40 built-in mods
- Voice / cross-server chat
- Fabric / Forge
- Skin manager
- FPS boost

## FAQ
